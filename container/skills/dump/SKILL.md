# Dump

## What this is for

Mental clutter: 50 thoughts running at once. The brain keeps cycling through open loops — things undone, decisions unmade, things to remember — and that cycling consumes working memory that should be available for the actual task. This skill empties the buffer.

## How to run it

If the invocation already contains the dump, sort it — don't ask them to repeat it. Otherwise say: "Tell me everything that's in your head right now. Don't organize it. Just dump." Then wait for the full dump without interrupting.

Before sorting, run `date`. "Due Thursday" means something different on Thursday.

---

## The sort

You sort. They confirm. Put each item in exactly one bucket:

**Now** — action today: blocking something, or a real consequence if delayed. Aim for 3 or fewer.
**Later** — real task, not today
**Decide** — not a task yet; needs a choice first
**Delegate** — someone else does the work; the user's whole action is one message to them
**Discard** — noise, hypotheticals, someday-wants, things they can't act on

Edge rules:
- A nagging worry a 5-minute check would settle ("I think I forgot to pay someone") is a task — Now or Later — not Discard.
- A holding reply ("got it, back to you Monday") is not delegation. The work stays in Now or Later, and the reply can be its one-line action.
- Unknown severity (a bug that might be critical): put it where it most likely belongs and add "(→ Now if <condition>)". Don't ask before sorting.

---

## Output format

If they asked for a plan ("plan my week"), decline in one line: the sort *is* the plan; a week plan is one more thing to manage.

NOW (do today):
• <item> — <one-line action>

LATER (real, not today):
• <item>

DECIDE (needs a choice first):
• <item> — <the actual decision>

DELEGATE (one send):
• <item> — <to whom / what to send>

DISCARD (letting go):
• <item>

Annotate only Now, Decide, and Delegate items. Later and Discard are bare, apart from a "(→ Now if …)" tag.

---

## After the sort

Two questions only:

1. "Does NOW feel right?" — If more than 3-4 items, help them cut: what has a consequence today vs. what just feels urgent?
2. "What's the first one?" — If they stall, use the start skill on the top NOW item.

## What not to do

- Do not ask the user to sort their own dump.
- Do not turn the dump into a schedule or project plan.
- Do not keep everything in NOW. Scarcity of NOW is the point.
